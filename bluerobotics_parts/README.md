# bluerobotics_parts

Shared part library for the Blue Robotics vehicle models: one URDF xacro
macro per part (`urdf/`), the modeler deliveries (`models/`: glTF meshes and
collision SDF), the assembly dispatcher (`urdf/assembly.xacro`), the
bootstrap tool (`sdf_to_part.py`) and the review world (`parts_check.sdf`).

Documentation: <https://honurobotics.github.io/bluerobotics_models/>, in
particular [Parts](https://honurobotics.github.io/bluerobotics_models/lyrical/design/parts.html),
[Slots and assembly](https://honurobotics.github.io/bluerobotics_models/lyrical/design/slots.html)
and [Add a part](https://honurobotics.github.io/bluerobotics_models/lyrical/how-to/add-part.html).
