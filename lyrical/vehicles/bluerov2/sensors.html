Sensors

Sensors are parts fitted into slots. The concepts live in Slots and assembly, the vehicle’s slots and their accepted types in the configuration page, and new sensors can be added following the Add a sensor part guide. The grippers live with the actuators.

DVL

ROS Topic

Description

Message type

/bluerov2/dvl/velocity

Bottom track velocity

marine_acoustic_msgs/msg/Dvl

Topic bases follow /<namespace>/<instance>/...: empty a slot and its topics disappear, rename the instance and they follow, and per part topic / gz_topic / ros_topic overrides in the config rename the base. Sensor messages carry the part’s own link as frame_id, which TF resolves; cameras deliberately use the body frame (x forward), not a REP 145 optical frame.
