# Worlds

| World | Package | Contents |
|---|---|---|
| `blueboat_water.sdf` | `blueboat_gazebo` | water only: graded buoyancy (seawater below z 0) enabled on `blueboat::hull_displacement`, seabed at 3 m, visual surface, sensors system. What `sim.launch.xml` spawns the boat into; the template for your own world |
| `blueboat_playground.sdf` | `blueboat_gazebo` | the same plus the default composed model included; `gz sim` it directly with no ROS |
| `bluerov2_pool.sdf` | `bluerov2_gazebo` | pool basin with deck: graded buoyancy (seawater below z 0) enabled on `bluerov2::buoyancy_displacement`, visual surface, sensor and render backends. What `sim.launch.xml` spawns the vehicle into |
| `bluerov2_playground.sdf` | `bluerov2_gazebo` | the same scene plus the default composed model included; `gz sim` it directly with no ROS |
| `bluerov2_water.sdf` | `bluerov2_gazebo` | open water: the same systems and buoyancy with a bare seabed, no pool. Pass it to `sim.launch.xml` with `world:=`; the template for your own world |
| `parts_check.sdf` | `bluerobotics_parts` | every part macro as its own static model on a grid, for reviewing inertia, collisions and visuals (generated by `parts_check_world.py`) |
| `parts_gallery.sdf` | `bluerobotics_parts` | every modeler delivery (`model.sdf`) laid out for review |
