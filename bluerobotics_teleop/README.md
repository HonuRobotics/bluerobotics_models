# bluerobotics_teleop

Gamepad teleoperation for the BlueROV2 and the BlueBoat: `joy_node`,
`teleop_twist_joy` and the `twist_to_thrust` mixer, with a mapping
walkthrough for new gamepads.

```bash
ros2 launch bluerobotics_teleop teleop.launch.py vehicle:=bluerov2   # or blueboat
```

Documentation:
[Teleoperate with a gamepad](https://honurobotics.github.io/bluerobotics_models/lyrical/how-to/teleop.html).
